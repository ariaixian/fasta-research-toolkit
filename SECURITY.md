# Security policy

## Supported versions

Security fixes are applied to the latest release on the default branch.

## Private reporting

Use GitHub's private vulnerability reporting feature for this repository. Do not open
a public issue containing leaked data, credentials, private paths, or identifying
details.

Include the affected version, a minimal reproduction using synthetic data, and the
impact. Do not attach real research inputs.

## Scope

Relevant reports include identifier disclosure, unsafe file handling, path traversal,
secret exposure, or validation behavior that could cause private material to be
published. Scientific interpretation and dataset-specific conclusions are outside the
scope of this software repository.
